# Redistribution Notes

This archive is designed for public GitHub and Zenodo release.

## Included

- COCO-derived benchmark annotations.
- Axis and direction labels for the curated benchmark subset.
- Split files and COCO image IDs.
- Aggregate statistics and result tables.
- Sanitized protocol configuration.
- Reconstruction and validation scripts.

## Excluded

- COCO images.
- Symlinks to local image files.
- Training-framework source code.
- Experiment logs, tracker identifiers, scheduler metadata, and private run
  directories.
- Credentials, tokens, model weights, or proprietary artifacts.
- Any internal or non-COCO dataset artifacts.

## COCO Terms

The official COCO terms state that COCO annotations and the COCO website are
licensed by the COCO Consortium under CC BY 4.0, while COCO does not own the
image copyrights. Users are responsible for image use under the applicable
source-image terms.

Official COCO terms: https://cocodataset.org/#termsofuse
